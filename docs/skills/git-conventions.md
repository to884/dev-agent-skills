# git-conventions

ブランチ名、コミットメッセージ、プルリクエスト、履歴をこのリポジトリの規約にそろえます。
たとえば「この差分に合うブランチ名とコミットメッセージを提案してください」と依頼します。

## ブランチ名とコミットメッセージ

ブランチ名は `<type>/<short-description>` の形式で、説明部分は小文字とハイフンを使い、7 語以内に収めます。
Claude Code や Codex が自動で付けた名前は、そのまま使います。

コミットメッセージは Conventional Commits の形式にそろえます。
scope は省略でき、付ける場合は変更した機能や領域を示します。
説明は日本語で書き、動詞で終えます。

```text
docs/add-skill-guides
docs(skills): スキルごとの利用ガイドを追加した
```

## コミットの粒度とプルリクエスト

1 つのコミットには 1 つの論理的な変更を入れます。機能変更とリファクタリングは分けます。
プルリクエストのタイトルは主要なコミットの type に合わせます。
説明はリポジトリのテンプレートに従い、テンプレートがなければ変更内容、理由、確認方法を書きます。
履歴を整理するリベースは push 前のローカルブランチで行い、統合はプルリクエストのマージで行います。
