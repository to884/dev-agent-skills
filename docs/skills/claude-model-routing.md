# claude-model-routing

Claude Code で作業を始める前に、Claude のモデルと effort を選ぶためのスキルです。
たとえば「この設計変更をどの Claude モデルで進めるか、判断の根拠も示してください」と依頼します。

## 作業の性質からモデルを選ぶ

作業の難しさ、後の工程まで保持する判断や制約、検査をすり抜けた誤りの訂正コスト、作業量に対する判断の少なさを見ます。

| このスキルでの割り当て | 条件 |
| --- | --- |
| Claude Fable 5.2 | 難しさ、後の工程まで保持する判断や制約、訂正コストのうち 2 つ以上が大きい |
| Claude Haiku 5.5 | 作業量に対して判断が少なく、成果を機械的に検査できる |
| Claude Sonnet 5.5 | 既存の手順やパターンに沿い、成果を機械的に検査できる |
| Claude Opus 5.5 | 既定。上の条件に該当しない作業 |

モデルを切り替える前に、現在のモデルで effort を調整できるかを考えます。
検査で合否が分かる作業は `low` で始め、検査に通らなかった分だけ既定の effort でやり直す方法もあります。

## 委譲するか、会話のモデルを切り替えるか

途中の相談が不要で、必要な情報を依頼文にまとめられ、報告を受け取れば足りる作業は、Claude Code の `Agent` ツールで委譲できます。
会話の文脈を持ったまま利用者とやりとりする必要がある場合は、作業の区切りでモデルメニューからの切り替えを提案します。
切り替え先のモデルでは会話履歴をもとにキャッシュを作り直すため、提案には切り替え直後の費用と、その後の出力単価を分けて示します。
