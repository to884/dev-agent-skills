# japanese-tech-writing

技術記事、書籍の章、解説文を書くときに、主張、因果関係、用語を正確にそろえるスキルです。
新規執筆、既存文書の推敲、公開前チェックに使えます。

## 依頼の種類

| やりたいこと | 依頼例 | 受け取るもの |
| --- | --- | --- |
| 新しく書く | 「新任の開発者向けに、API の再試行条件を説明する記事を書いてください」 | 読み手と目的に合わせた本文 |
| 推敲する | 「`docs/retry.md` を推敲し、曖昧な因果関係や用語を直してください」 | 修正版と主な修正理由 |
| 公開前に採点する | 「`docs/retry.md` を公開前チェックにかけてください」 | 各軸の点数、減点理由、書き直しの要否 |

公開前チェックでは、主張、厳密さ、主体性、具体性、簡潔さ、語りを各 10 点で評価します。
合計が 42 点未満か、いずれかの軸が 2 点以下なら書き直しと判定します。
文章を簡潔にする際も、正確さに関わる条件や留保は残します。

文章の規範、避ける語彙、公開前の評価項目は、それぞれ参照資料にまとまっています。
