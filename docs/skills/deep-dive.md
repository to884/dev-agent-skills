# deep-dive

複数の観点や資料を突き合わせる Web 調査を、出典付きのレポートにまとめます。
Web 検索とサブエージェントを使える環境で、技術の比較や背景調査を依頼するときに使います。

## 依頼例

```text
/deep-dive SQLite と PostgreSQL で、書き込みの競合が起きる条件と、アプリ側で取れる対策を比較してください
```

## 調査の進み方

1. 大きな問いを小さな問いに分け、どの問いの答えが先に必要かを表で示します。
2. 独立した問いをサブエージェントに並列で割り当てます。後続の調査には、前提となる問いの結果を渡します。
3. 結論を変えうる未解決の論点があれば、対象を絞って最大 1 回追加調査します。
4. 調査結果をテーマごとにまとめ、未解決の論点と出典を添えます。レポートは対象プロジェクトの `docs/deep-dive/YYYY-MM-DD-<topic>.md` に保存します。
