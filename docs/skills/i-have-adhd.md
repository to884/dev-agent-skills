# i-have-adhd

ADHD の読み手が次の行動や進捗を見つけやすいように、エージェントの応答を整えます。

## 有効にする

```text
/i-have-adhd
```

設定は、そのセッションで話題を変えても続きます。
通常の応答に戻すには、同じセッションで `stop adhd mode` または `normal mode` と伝えます。

## 応答はどう変わるか

- 最初の行に、今すぐ実行できる行動やコマンドを置きます。
- 複数の手順には番号を振り、会話が続く場合は現在どの手順にいるかを示します。
- 時間の見積もりは分や時間で伝え、完了した成果はファイル名などで示します。
- やり残しがあれば、最後にすぐ取りかかれる行動を 1 つ示します。

詳しい説明を頼んだ場合は、見出しを付けて必要な分だけ説明します。
